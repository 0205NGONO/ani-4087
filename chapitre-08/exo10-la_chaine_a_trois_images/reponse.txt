Le minimum d'images : dans le modele, pour eviter tout conflit pendant L trames de lecture, il faut L + 1 images. Quand L vaut 2, deux images entrent en conflit sur quatre des six trames ; trois images n'en ont aucun. Pour L = 0, une image suffit.

Sur le simulateur : la trace ci-dessus a ete refaite le 5 novembre en faisant tourner la salle depuis la racine du projet, nuanceurs presents. Elle suit une chaine de trois images modelisee par les indices 0, 1 et 2. Le kit expose la swapchain de fenetre, mais pas d'index de swapchain XR ; cette trace n'est donc pas une mesure d'un casque. Dans le simulateur de l'exercice, L vaut 0 : le cycle a trois images n'evite aucun conflit supplementaire par rapport a une seule image.
